# 06. 展示当日の運用マニュアル(スタッフ向け)

専門知識がなくても運用できるように書いています。困ったら [07_troubleshooting.md](07_troubleshooting.md) を見てください。

## 1. 開場前チェックリスト

- [ ] Mac が電源アダプタにつながっている(スリープ設定オフ、[05](05_kiosk_launch.md))
- [ ] インターネットに接続できている(Gemini 用。切れてもテンプレートで体験は続きます)
- [ ] USB マイクが接続され、口元 10〜20cm の位置にある([04](04_audio_devices.md))
- [ ] スピーカーが体験者の近くにあり、音量が適切
- [ ] `scripts/start.command`(Windows は `start.bat`)で起動した
- [ ] 待機画面が全画面で表示されている(起動直後は 1〜2 分「準備中」の場合あり)
- [ ] スタッフが 1 回、最初から最後まで試した(録音 → 着信 → 通話 → 終話)
- [ ] 隠しリセット(左上 3 秒長押し)で待機画面に戻ることを確認した
- [ ] 展示の説明文に「あなたに似た声」と書いてある(「そっくり」は使わない)
- [ ] ティッシュや椅子など、体験者が落ち着ける環境がある

## 2. 体験者への案内

### 基本の声かけ
「自分の失敗した経験を、20 秒以上話してみてください。しばらくすると、10 年後の自分から電話がかかってきます。」

### 必ず伝えること
1. **同意**: 録音と、文字に起こした内容が外部の AI サービス(Google Gemini)に送られること(未来の自分の読み上げの声づくりにも Gemini を使いますが、送るのは物語の文章だけで、体験者の声は送られません)、体験後にデータは消えること、物語は AI による創作で未来の予言ではないことは、同意画面に書かれています。読んでから進んでもらってください。(S-01, S-05, S-23)
2. **未成年**: 保護者の同伴と同意のもとで体験してもらいます。(S-06)
3. **本人の声のみ**: 他人の声や、スピーカー・スマホから流した音声は使わないでください、と伝えます。(S-11)
4. **声の似方**: 「あなたに似た声」になります。そっくりにはなりません、と伝えて期待を上げすぎないようにします。
5. **話し方のヒント**: 「いつ、何に挑戦して、どうなったか」を話すとよい、と案内します。
6. **持ち帰り**: 音声の保存・ダウンロードはできません。(S-10)

### 話すことが思いつかない人には
軽い失敗(テスト、試合、発表、料理など)を話してもらってかまいません。深い話を無理に促さないでください。

### 通話中の「覚えてる?」で間が空くことについて

通話の途中で、未来の自分が「ねえ、覚えてる?」などと問いかけ、**少し間が空きます**。これは故障ではありません。

- 体験者が声に出して答えてもよく、答えなくてもかまいません。答え終わると、あるいは **答えずにいても約 5 秒たつと、自動で続きが再生されます**。
- 画面には小さく「…」が出るだけです。戸惑っている人には、次のように声をかけてください。
  - 「未来の自分が話しかけています。**思ったことを声に出して答えても、黙って聞いていてもだいじょうぶ**ですよ。」
  - 「ためらっていても、そのうち続きが始まります。」
- 通話中は生活音(カフェのざわめきなど)がかすかに流れます。演出です。
- **プライバシー**: この返事待ちでは、体験者の答えは **録音も保存も送信もされません**(マイクの音量を見ているだけです)。聞かれた場合はそう説明してください。
- 周囲が騒がしいと、黙っていても待ちが長引いたり、答えても反応しないことがあります。続きが再生されないのが長引く場合は [07](07_troubleshooting.md)、開場前の調整は [04](04_audio_devices.md) を見てください。

## 3. 気持ちが揺れた人への対応(S-24)

- 体験後に涙ぐんだり、沈んだ様子の人には、静かに声をかけます。「ゆっくりしていってください」「話してくれてありがとう」など。
- 話の内容を根掘り葉掘り聞かない。評価やアドバイスをしない。
- 深刻な話(死別、いじめ、虐待、自傷など)をされた場合は、アプリが寄り添う内容に切り替わります。スタッフは受け止めて傾聴し、必要なら保護者や責任者に引き継いでください。
- 主催者が用意した相談窓口の案内(あれば)を手渡します。

## 4. プライバシー

- 問いかけのあとの返事待ちで話した内容は、録音も保存もされません。
- 録音・文字起こし・物語・合成音声は、体験終了後(または待機に戻るとき、リセット時)に **自動で削除** されます。
- ログには処理時間とエラー種別だけが残り、話の内容は残りません。
- 他の来場者に内容が聞こえないよう、スピーカーの位置と音量に気を配ります。待機列は少し離します。
- 体験者が話している間は、近くで聞き耳を立てないようにします。

## 5. 隠しリセット(強制リセット)

画面の **左上の角を 3 秒間長押し** します。進行中の体験が中断され、データがすべて消えて待機画面に戻ります(30 秒以内に復帰)。次の場合に使います。

- 体験者が途中でやめた、離席した
- 画面が進まない・固まったように見える
- 想定外の内容で体験を止めたい

## 6. 体験中によくある状況

| 状況 | 対応 |
|---|---|
| 「声が小さい」と出る | マイクに近づいて、もう少し大きな声で話してもらう |
| 「もう少し詳しく」と出る | 20 秒以上話してもらう(状況、気持ち、結果など) |
| 接続中が長い(1〜3 分) | そのまま待ってもらう。3 分たつとブラウザ音声で代替再生される。頻発するなら [07](07_troubleshooting.md) |
| 着信に出ない | 30 秒で不在着信表示のあと再着信する |
| 声が本人に似ていない | 期待値を伝えつつ、次の人のためにマイク位置を確認 |

## 7. 終了手順

1. 最後の体験者が待機画面に戻ったことを確認する
2. Chrome を終了する(macOS: `Cmd + Q` / Windows: `Alt + F4`)
3. サーバーのターミナルで `Ctrl + C`(ウィンドウを閉じてもよい)
4. 念のためデータが残っていないか、一時フォルダを確認する(通常は空)
5. スピーカー・マイクを片づける。`.env` や API キーを他人に見せない
6. 不具合や気づきがあれば、`logs/` の中身と一緒に担当者へ共有する

## 8. ログの場所

`future-call/logs/` に保存されます(`config.yaml` の `logging.dir`)。記録されるのは処理時間、エラーの種類(例外名)、文字数などの数字のみです。不具合の連絡時にこのフォルダを添えれば原因調査に使えます。話の内容は入っていないので、共有しても問題ありません。
